# External pre-deadline sources (`kaggle_tuning/ext_sources.py`)

`source(name, year, g)` -> DataFrame[T1, T2, p, d] (T1 < T2 Kaggle IDs, all pairs of seeded teams; `d` = raw strength
difference). `standalone(...)` scores it. `export_all(dir)` writes CSVs (already in `data/kaggle/ext_pairs/`).
Slope `k` (p = sigmoid(k d)) is fitted walk-forward on earlier seasons of the same source (prior `K0` for the first
year); futures sources are native (k = 1). Raw files: `data/kaggle/ext_torvik_tm`, `ext_futures`, `ext_women_ratings`.

| source | gender / years | what, and publication evidence |
|---|---|---|
| `torvik_adjem`, `torvik_barthag` | M 2015-19, 2021-24 (+2025/26) | Torvik T-Rank **Time Machine** `barttorvik.com/timemachine/team_results/<SelectionSunday>_team_results.json.gz` (a date-capped export, not end-of-season). HTTP `Last-Modified`: 2021 Mar 15, 2022 Mar 14, 2023 Mar 13, 2024 Mar 18 15:30 UTC (Monday after Selection Sunday). 2015-19 files were regenerated by Torvik in Sep-Nov 2019 as as-of-date recomputations; records match Selection Sunday (2015 Kentucky 34-0, 2018 Virginia 31-2). adjem = adjoe - adjde; barthag as log-odds. |
| `futures_M` | M 2021-24 | Pre-tournament championship futures -> team strengths r such that bracket title probabilities (P(i>j)=sigmoid(r_i-r_j), exact DP over the Kaggle slots) equal the vig-removed (proportional) odds; ridge 0.02 toward a seed prior with slope fitted on earlier seasons only. 2021: VegasInsider archived 2021-03-16 22:46 UTC; 2022: VegasInsider 2022-03-17 03:46 UTC (two books averaged); 2023: VegasInsider "Opening Odds" 2023-03-13 23:40 UTC; 2024: scoresandodds.com 2024-03-19 17:32 UTC (6 books averaged). All via web.archive.org, all pages already list the 68 bracket teams and predate the deadline. |
| `futures_W` | W 2023 only | same VegasInsider 2023-03-13 page, "Women's Tournament Opening Odds" (66/68 quoted; the other two get the smallest quoted prob). No women's futures page was archived for 2021, 2022, 2024. |
| `wnet` | W 2021-24 | NCAA women's NET **rank** (rating = -ln rank): ncaa.com via web.archive.org (2021-03-16 "through games Mar 14", 2022-03-15 "Mar 13", 2024-03-18 "Mar 17"); 2023 = Kaggle maheshnanavare/ncaa-2023-women-regular-season-rankings (2023-03-14). 2021 uses prior k=0.7. |
| `wmassey` | W 2024 | Kaggle jaredcross/massey-export-wncaa, uploaded 2024-03-10 (before women's conference tournaments ended). One year, so no walk-forward k (K0 prior 0.5 is not calibrated; use `d` and your own scaling). |
| `r64_ml` | M 2015-19, 2021-24, **partial** | men's round-of-64 moneylines whose bookmaker `last_update_utc` is before 00:00 UTC of the first R64 day; 4-23 games/yr. From the closing-odds Kaggle table; stale quotes, vig removed, books averaged. |
